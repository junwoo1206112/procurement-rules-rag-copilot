- 재현: `--live-llm`, `--live-resume`, `--live-overwrite`와 Docker의 `data/`·`docs/` 바인드 마운트로 평가 산출물을 보존한다.

## 경고 및 후속 개선

### WARNING — 실제 생성 인용 일치가 낮다

대표 표본에서 3/7만 정답 근거를 인용했다. 일정·평가기준·제출서류 질의가 공고 개요 청크로 흐르는 사례가 확인됐다. 따라서 이 프로젝트는 현재 **근거 실패를 감지·보류·분석하는 RAG 포트폴리오**로 소개해야 하며, 높은 답변 정확도나 운영 배포 준비 완료를 주장해서는 안 된다.

후속 변경에서는 도메인 질의 확장 또는 재순위화, 구조화 출력 재시도·제약을 실제 72문항 평가로 검증한다.

### SUGGESTION — 의존성 경고

FastAPI 테스트 클라이언트가 사용하는 `httpx` 관련 사용 중단 경고 1건이 있다. 기능 실패는 아니지만, 다음 의존성 업데이트 때 호환 버전을 검토한다.

### SUGGESTION — 공개 저장소 연결

현재 폴더는 Git 저장소가 아니다. 코드 자체의 마감과 별개로, 지원용 공개를 하려면 새 Git 저장소를 만들거나 기존 저장소에 연결한 뒤 `.env`가 포함되지 않았는지 확인하고 올린다.

## 최종 판정

구현·테스트·재현·실패 분석이라는 프로젝트 종료 게이트는 충족했다. 공개 포트폴리오로도 마감 가능하지만, 소개문은 ‘고품질 정답 서비스’가 아니라 ‘근거 중심 RAG의 안전장치와 실제 품질 측정·개선 과정’에 초점을 맞춘다.
