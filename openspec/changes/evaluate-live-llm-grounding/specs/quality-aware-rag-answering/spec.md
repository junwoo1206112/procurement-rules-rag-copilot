## MODIFIED Requirements

### Requirement: 안전한 답변 상태를 구분한다
시스템은 인용 검증을 통과한 생성 답변, 근거 부족 보류, 생성 검증 실패 후 원문 발췌를 서로 구분 가능한 상태로 반환해야 한다(MUST). 모든 상태에서 반환된 인용은 실제 검색 청크와 일치해야 한다(MUST). 실제 모델이 생성한 답변은 선택 근거·반환 인용·상태를 사후 검토할 수 있도록 평가 실행 결과에 연결되어야 한다(MUST).

#### Scenario: 여러 후보에서 claim 검증에 실패한다
- **WHEN** 생성 모델의 claim이 유효한 citation ID 또는 최소 어휘 근거를 충족하지 못한다
- **THEN** 시스템은 검증되지 않은 생성 문장을 반환하지 않고 검증된 원문 발췌와 실제 인용을 반환한다

#### Scenario: 질문과 일치하는 근거가 없다
- **WHEN** 검색 결과에 질문과 어휘적으로 일치하는 근거가 없다
- **THEN** 시스템은 생성 모델을 호출하지 않고 근거 부족 상태와 빈 인용 목록을 반환한다

#### Scenario: 실제 생성 답변을 사후 검토한다
- **WHEN** 모델이 `grounded` 상태의 답변을 반환한 뒤 실제 LLM 평가를 실행한다
- **THEN** 시스템은 해당 답변의 선택 근거와 반환 인용을 검토 가능한 평가 결과에 연결한다
