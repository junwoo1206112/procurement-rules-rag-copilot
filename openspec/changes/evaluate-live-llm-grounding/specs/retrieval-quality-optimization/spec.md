## MODIFIED Requirements

### Requirement: 답변 상태별 품질을 고정 평가 세트에서 측정한다
시스템은 버전 관리되는 평가 세트에서 검색 품질과 함께 생성 답변·원문 발췌·근거 부족 상태의 건수와 비율을 산출해야 한다(MUST). 측정 결과에는 데이터셋과 코퍼스 버전이 포함되어야 한다(MUST). 결정론적 근거 계약 평가와 실제 LLM 생성 평가를 서로 다른 측정 유형으로 기록하고, 실제 생성 평가에는 모델·프롬프트·실행 성공 여부를 포함해야 한다(MUST).

#### Scenario: 구성별 평가를 실행한다
- **WHEN** 두 개 이상의 검색 또는 문맥 구성으로 고정 평가가 실행된다
- **THEN** 시스템은 각 구성의 Recall@k·MRR·nDCG·인용 precision/recall 및 답변 상태별 비율을 같은 리포트에 기록한다

#### Scenario: 실제 모델 평가를 실행한다
- **WHEN** 모델이 준비된 환경에서 고정 평가 세트로 실제 LLM 생성 평가를 실행한다
- **THEN** 시스템은 결정론적 근거 계약 결과와 실제 생성의 근거·인용 검토 결과를 분리해 기록한다
