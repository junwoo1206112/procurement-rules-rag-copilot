## 1. 평가 결과 계약

- [x] 1.1 실제 LLM 실행의 질의별 레코드(질문·상태·생성문·선택 근거·반환 인용·정답 근거·실행 분류·재현 메타데이터)를 정의하고, 비밀 키·원문 본문이 기록되지 않는 단위 테스트로 검증한다.
- [x] 1.2 답변 가능 질의의 인용 정답 근거 일치, 답변 불가 질의의 보류 적절성, `grounded_demo`, 모델·시간 초과·형식 오류를 서로 분리하는 집계 함수를 구현하고, 분모가 완료 실행만 포함하는 테스트를 통과시킨다.

## 2. 실제 생성 평가 실행

- [x] 2.1 `OllamaAnswerer`의 실제 실행에서 평가에 필요한 모델명·프롬프트 해시·선택 근거를 안전하게 추출하는 경로를 추가하고, 기존 API 응답 테스트가 그대로 통과하는지 확인한다.
- [x] 2.2 명시적 CLI 옵션으로 실제 LLM 평가를 실행해 별도 JSON 체크포인트에 기록하고, 결정론적 `evaluation-results.json`을 변경하지 않는 통합 테스트를 추가한다.
- [x] 2.3 질의 ID 또는 제한 수로 실행 범위를 좁히고 중단·실패 레코드를 보존해 재실행 가능하게 만들며, 네트워크 없는 답변자 더블 테스트로 이를 검증한다.

## 3. 리포트와 검토 자료

- [x] 3.1 전체 질의·완료 실행·인프라 실패·인용 정답 근거 일치·안전 보류·검토 필요 건수와 각각의 분모를 표시하는 실제 LLM 평가 Markdown 리포트를 생성하고, 리포트 렌더링 테스트를 통과시킨다.
- [x] 3.2 인용 불일치·`grounded_demo`·문서 비교 질의를 우선 표시하는 사람 검토용 사례 목록을 생성하고, 생성문 의미 판정이 자동 법률 정확도 판정으로 오해되지 않는지 테스트와 문서로 확인한다.
- [x] 3.3 README·평가 리포트·전문가 인터뷰 기록을 실제 생성 평가와 결정론적 근거 계약의 차이가 명확하도록 갱신하고, 이전 성능 수치를 과장하는 문구가 없는지 검색으로 검증한다.
