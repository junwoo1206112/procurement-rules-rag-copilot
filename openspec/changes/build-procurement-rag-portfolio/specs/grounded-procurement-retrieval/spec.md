## Purpose

조달 문서의 조항·공고번호·일정처럼 정확한 키워드와 의미적 유사도가 모두 중요한 질의를 근거 청크로 안정적으로 연결한다.

## ADDED Requirements

### Requirement: 구조와 메타데이터를 활용해 검색한다
시스템은 구조 기반 청크를 검색하고, 발행 기관, 문서 유형, 공고번호, 발행일 등 이용 가능한 메타데이터로 결과를 MUST 제한할 수 있어야 한다.

#### Scenario: 기관 필터가 있는 질의를 검색한다
- **WHEN** 사용자가 특정 기관 필터와 함께 질문한다
- **THEN** 시스템은 해당 기관 메타데이터를 가진 문서 청크만 검색 결과로 반환한다

### Requirement: 하이브리드 검색 결과를 재정렬한다
시스템은 의미 기반 검색과 키워드 기반 검색의 후보를 결합하고, 최종 근거를 재정렬해 반환해야 한다. 각 결과에는 검색 점수와 원문 위치가 MUST 포함되어야 한다.

#### Scenario: 공고번호를 포함한 질의를 검색한다
- **WHEN** 사용자가 특정 공고번호와 제출 기한을 질문한다
- **THEN** 시스템은 정확히 일치하는 공고번호의 관련 조항을 우선 근거 후보로 반환한다

#### Scenario: 검색 근거가 부족하다
- **WHEN** 최종 후보가 최소 관련성 기준을 충족하지 못한다
- **THEN** 시스템은 답변 생성에 사용할 근거가 없음을 반환한다
