## Purpose

검색된 공개 문서 안의 근거만 사용해 질의에 답하고, 사용자가 원문 위치로 검증할 수 있는 인용을 제공하여 환각 위험을 줄인다.

## ADDED Requirements

### Requirement: 근거 기반 답변과 인용을 반환한다
시스템은 검색된 문맥에 의해 뒷받침되는 정보만 답변에 포함해야 하며, 핵심 주장마다 문서명, 섹션(법령은 조항), 원문 링크를 포함한 인용을 MUST 반환해야 한다. 원문이 페이지 기반 문서인 경우 페이지도 포함해야 한다.

#### Scenario: 근거가 있는 참가 자격 질문에 답한다
- **WHEN** 검색 결과에 참가 자격 조항이 포함된 질문이 입력된다
- **THEN** 시스템은 자격 요건을 요약하고 해당 조항의 문서명·조항·원문 링크를 함께 반환한다

### Requirement: 근거가 부족하면 답변을 보류한다
시스템은 관련성이 충분한 근거가 없거나 인용을 검증할 수 없을 때, 추정 답변을 생성하지 않아야 한다. 이 경우 시스템은 답변 생성을 MUST 보류한다.

#### Scenario: 문서에 없는 내용을 질문한다
- **WHEN** 사용자가 색인 문서가 다루지 않는 입찰 조건을 질문한다
- **THEN** 시스템은 확인 가능한 근거를 찾지 못했다고 안내하고 추정 내용을 제공하지 않는다

### Requirement: 인용 연결의 정합성을 검사한다
시스템은 답변의 각 핵심 claim이 하나 이상의 실제 색인 청크를 참조하는지 MUST 검사하고, 참조 ID·문서 위치·최소 어휘 근거가 불일치한 답변은 사용자에게 반환하지 않아야 한다.

#### Scenario: 존재하지 않는 페이지 인용이 생성된다
- **WHEN** 답변 후보의 인용 페이지가 원문 메타데이터와 일치하지 않는다
- **THEN** 시스템은 해당 답변 후보를 실패로 처리하고 검증 가능한 인용만 포함한 결과 또는 근거 부족 응답을 반환한다

#### Scenario: claim이 검색 근거를 참조하지 않는다
- **WHEN** 생성 모델의 claim에 유효한 citation ID 또는 최소 어휘 근거가 없다
- **THEN** 시스템은 전체 생성 답변을 보류하고 검증된 원문 발췌 또는 근거 부족 응답만 반환한다
