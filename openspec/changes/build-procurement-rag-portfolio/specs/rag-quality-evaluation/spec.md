## Purpose

동일한 질의와 정답 근거를 사용해 검색 방식별 품질·인용 정합성·응답 성능을 측정하고, 포트폴리오에서 재현 가능한 개선 근거를 제공한다.

## ADDED Requirements

### Requirement: 고정 평가 세트와 근거 라벨을 제공한다
시스템은 자격요건, 일정, 제출물, 평가 기준, 문서 비교, 답변 불가 질의를 포함하는 고정 평가 세트와 각 질의의 정답 근거를 MUST 버전 관리한다.

#### Scenario: 문서 단위로 분리된 평가를 실행한다
- **WHEN** 평가 실행이 시작된다
- **THEN** 시스템은 동일 문서의 유사 질의가 비교 대상 간에 섞이지 않도록 문서 또는 공고 단위 분할 정보를 사용한다

### Requirement: 검색과 인용 성능을 비교 보고한다
시스템은 Dense 검색, 하이브리드 검색, 하이브리드+재정렬 결과를 같은 평가 세트에서 비교하고 Recall@k, MRR, nDCG, 인용 정밀도·재현율, p50/p95 지연시간을 MUST 보고한다.

#### Scenario: 검색 방식 비교를 완료한다
- **WHEN** 평가가 완료된다
- **THEN** 시스템은 각 방식의 측정값, 실행 환경, 데이터셋 버전, 실패 사례 링크를 포함한 리포트를 생성한다
