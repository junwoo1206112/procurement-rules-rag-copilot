## Why

공개 조달·입찰 문서는 자격요건, 제출 서류, 일정, 평가 기준처럼 정확한 근거 확인이 필요한 정보를 담고 있지만, 긴 PDF와 표 중심 형식 때문에 필요한 조항을 빠르게 찾기 어렵다. 넥스인테크놀로지의 RAG·LLM 직무와 직접 맞닿는 문서 파싱·검색 품질 개선·로컬 서빙 역량을 검증 가능한 포트폴리오로 보여주기 위해 지금 구축한다.

## What Changes

- 저작권법 제7조의 보호 제외 범주에 해당하는 국가법령정보센터의 조달 법령·행정규칙을 우선 등록하고, 출처·수집 시각·이용 근거를 보존하는 색인 파이프라인을 추가한다.
- 제목 계층과 표를 보존하는 구조 기반 청킹, Dense+BM25 하이브리드 검색, reranking을 제공한다.
- 근거가 있는 경우에만 답하고 문서명·섹션(법령은 조항)·원문 링크를 표시하는 인용형 질의응답 API와 웹 UI를 추가한다. 페이지가 있는 PDF는 페이지를 함께 표시한다.
- Ollama, FastAPI, 검색 저장소를 Docker Compose로 재현 가능하게 실행하고, 검색·인용 품질과 지연시간을 평가한다.
- 다른 프로젝트에도 재사용할 수 있도록 전문가 역할 기반 요구사항 인터뷰와 OpenSpec 명세화 절차를 Markdown 템플릿으로 제공한다.

## Capabilities

### New Capabilities

- `procurement-document-ingestion`: 공개 조달 문서를 출처 메타데이터와 함께 안전하게 수집·파싱·색인한다.
- `grounded-procurement-retrieval`: 메타데이터 필터를 포함한 하이브리드 검색과 reranking으로 근거 청크를 찾는다.
- `cited-rag-answering`: 로컬 LLM이 검색 근거에 기반해 답하고 검증 가능한 인용을 반환한다.
- `rag-quality-evaluation`: 고정 질의셋으로 검색·인용·시스템 성능을 비교하고 보고한다.

### Modified Capabilities

- 없음.

## Impact

- 새 Python 서비스(FastAPI), 문서 처리기, 임베딩·검색 저장소, Ollama 연결, 반응형 웹 UI, Docker Compose, 평가 데이터와 리포트가 추가된다.
- 외부 공개 법령·행정규칙의 원문 링크와 최소 메타데이터만 저장하며, 비공개·접근 제한·개인정보가 포함된 문서는 수집 대상에서 제외한다.
