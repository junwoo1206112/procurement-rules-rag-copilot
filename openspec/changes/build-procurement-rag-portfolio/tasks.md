## 1. 프로젝트 기반과 데이터 경계

- [x] 1.1 Python 서비스·웹 UI·테스트·Compose 기본 구조를 만들고, 빈 환경에서 개발 서버와 테스트 명령이 실행되는지 확인한다.
- [x] 1.2 공개 문서 매니페스트 스키마(원문 URL, 기관, 수집 시각, 문서 유형, 이용 조건 확인, 제외 사유)를 만들고 유효·무효 레코드 검증 테스트를 통과시킨다.
- [x] 1.3 국가법령정보센터의 조달 법령·행정규칙 HTML 원문 30~50개를 저작권법 제7조 이용 근거·출처와 함께 등록하고, 개인정보·접근 제한 문서가 제외 목록에 기록되는지 확인한다.

## 2. 문서 파싱과 구조 기반 청킹

- [x] 2.0 큐레이션 매니페스트의 허용 도메인 원문을 수집하고 제목·SHA-256·수집 시각을 검증해 색인하는 경로와 성공·실패 통합 테스트를 구현한다.

- [x] 2.1 PDF 텍스트·페이지·블록 추출기를 구현하고, 페이지 메타데이터가 유지되는 샘플 파싱 테스트를 통과시킨다.
- [x] 2.2 HWPX 구조 추출과 구형 HWP 명시적 거부 경로를 구현하고, 지원·미지원 형식 테스트를 통과시킨다.
- [x] 2.3 표를 독립 청크로 보존하는 변환을 구현하고, 제목·헤더·행 정보가 유지되는지 fixture 테스트로 확인한다.
- [x] 2.4 섹션 단위 청킹과 청크 메타데이터 저장을 구현하고, 조항 및 표가 경계에서 잘리지 않는지 샘플 문서로 검증한다.

## 3. 검색과 근거 기반 답변

- [x] 3.0 생성 결과를 claim·citation ID 구조로 검증하고, 검증 실패 시 원문 발췌 또는 근거 부족으로 보류하는 테스트를 구현한다.

- [x] 3.1 임베딩 색인과 BM25 색인을 구축하고, 문서·기관·공고번호 필터 검색 통합 테스트를 통과시킨다.
- [x] 3.2 Dense+BM25 후보 결합과 reranking을 구현하고, 공고번호 질의에서 정확 일치 조항이 상위 결과에 포함되는지 확인한다.
- [x] 3.3 최소 관련성 기준과 근거 부족 응답을 구현하고, 색인에 없는 질문이 생성 모델 호출 없이 보류되는지 테스트한다.
- [x] 3.4 로컬 Ollama 기반 답변 생성과 citation validator를 구현하고, 문서명·섹션·페이지·원문 URL이 실제 청크와 일치하는지 통합 테스트한다.
