## Purpose

여러 검색 후보 중 질문을 직접 뒷받침하는 근거만 생성 모델에 전달하고, 생성·보류·원문 발췌의 경계를 사용자가 검증 가능하게 만든다.

## ADDED Requirements

### Requirement: 관련 근거 중심의 생성 문맥을 구성한다
시스템은 질문과 문서명·조항·핵심 어휘가 직접 일치하는 검색 청크를 생성 문맥에 우선 포함해야 한다(MUST). 관련성이 낮은 후보는 답변의 claim 인용에 사용해서는 안 된다(MUST NOT).

#### Scenario: 직접 일치하는 조항을 질문한다
- **WHEN** 질문에 문서명 또는 조항의 핵심 어휘와 일치하는 청크가 검색된다
- **THEN** 시스템은 해당 청크를 우선 인용한 claim을 생성하고, 인용에는 실제 문서명·섹션·원문 URL을 반환한다

### Requirement: 안전한 답변 상태를 구분한다
시스템은 인용 검증을 통과한 생성 답변, 근거 부족 보류, 생성 검증 실패 후 원문 발췌를 서로 구분 가능한 상태로 반환해야 한다(MUST). 모든 상태에서 반환된 인용은 실제 검색 청크와 일치해야 한다(MUST).

#### Scenario: 여러 후보에서 claim 검증에 실패한다
- **WHEN** 생성 모델의 claim이 유효한 citation ID 또는 최소 어휘 근거를 충족하지 못한다
- **THEN** 시스템은 검증되지 않은 생성 문장을 반환하지 않고 검증된 원문 발췌와 실제 인용을 반환한다

#### Scenario: 질문과 일치하는 근거가 없다
- **WHEN** 검색 결과에 질문과 어휘적으로 일치하는 근거가 없다
- **THEN** 시스템은 생성 모델을 호출하지 않고 근거 부족 상태와 빈 인용 목록을 반환한다
