# 전문가 대화 기록 프레임워크

## 질문 축

1. 문제와 직무 적합성: 실제 사용 문제와 채용 직무 역량의 대응은 무엇인가?
2. 데이터와 안전성: 출처·이용 근거·민감정보·갱신 경계는 확인됐는가?
3. 설계와 대안: 선택한 구현이 더 단순한 대안보다 나은 이유와 비용은 무엇인가?
4. 품질과 실패: 같은 평가 세트, 기준선, 실패 처리, 재현 방법이 있는가?
5. 출시 판단: MVP 필수 흐름과 명시적 제외 범위는 무엇인가?

## 종료 게이트

- 데이터 출처와 이용 범위가 확인됐다.
- 최소 사용자 흐름과 실패 동작이 정의됐다.
- 비교 가능한 품질 지표가 있다.
- 데모·테스트·재현 방법이 정해졌다.
- 해결되지 않은 고위험 가정이 기록됐다.
