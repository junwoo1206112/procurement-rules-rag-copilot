# 데이터 등록 규칙

원문 파일은 저장소에 커밋하지 않습니다. 공개 문서를 등록하기 전에 다음을 확인하세요.

1. 발행 기관의 원문 URL에서 공개 접근이 가능한지 확인합니다.
2. 사이트의 이용 조건·저작권 안내를 확인하고, 개인 정보나 접근 제한 첨부물이 없는지 확인합니다.
3. 법령·고시·공고·훈령은 저작권법 제7조의 보호 제외 범주인지 확인하고 그 근거를 `usage_basis`에 기록합니다.
4. `manifest.example.json` 형식으로 원문 URL, 기관, 수집 시각, 형식, 이용 조건 확인 결과를 기록합니다.
5. 조건을 확인할 수 없는 문서는 `access_status: "unknown"` 또는 `"restricted"`와 `exclusion_reason`을 기록하고 색인하지 않습니다.

`procurement-rules-manifest.json`은 국가법령정보센터에서 조회한 조달청 행정규칙 30건의 메타데이터만 보관합니다. 원문은 저장소에 포함하지 않으며, 실행 시 각 원문 URL에서 수집·검증해야 합니다.

이 저장소의 테스트 데이터는 파이프라인 검증용 합성 fixture이며, 실제 공고·규정의 검색 성능을 뜻하지 않습니다.
